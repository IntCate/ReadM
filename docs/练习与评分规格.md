# 练习与评分规格

版本 v0.1。P3A 等待与 P3B 节奏练习为工作基线；P3C 自由跟随为候选研究项。基本练习不依赖大模型或云端实时判定。

## 会话输入和目标

开始前选择左手/右手/双手、连续小节范围、速度和模式。固定乐谱 revision 和展开后的演奏路径；用户练习期间不得修改谱面。目标由新起音组成：tie 后续片段不新增起音目标，slur 不合并目标。每个目标记录 occurrence、音高多重集合、相对时间和持续时长。

MIDI 无法可靠知道演奏者使用哪只手。分手练习仅选择该手目标，并告知另一手应停止弹奏；双手相同音高同时出现时，同键盘无法观测两次独立同音按压，匹配按可观测键集合去重，反馈标为共享同音目标，不能据此声称双手各自弹对。

## P3A 等待模式

当前目标接收新的 NoteOn。和弦在初始 120ms 可配置收集窗口内完成，必须各目标音均出现；不要求在窗口结束时所有键仍按住。窗口超时尚未齐音则保留当前位置，清空本轮候选并提示重试；额外音记为本轮错误，默认需重试当前目标。重复音必须重新触发，踏板维持声音不算起音。

等待模式只反馈音高与尝试，不输出节奏准确率。休止段不要求输入，也不自动沿墙上时间播放：当前目标完成后直接跳到下一个起音目标，界面仍显示中间休止；如需练习休止时长应使用节奏模式。

## P3B 节奏模式

倒数后以固定演奏计划推进，用户演奏不会改变谱速。输入事件减去校准固定偏移后，与时间窗口内最近未匹配的同音高目标一对一匹配；平局选择较早目标。默认起音容差为 min(150ms, 当前四分音符时长×0.25)，最低 40ms；默认值需通过学习者测试校准。

允许窗口闭合后再最终判定，闭合前反馈为 provisional，避免把迟到音先算漏音又算正确。错音为与当前目标时窗关联的错误音高，目标仍可随后匹配；漏音为时窗关闭后未匹配目标；无关联目标的输入为多音。相同输入不能同时计错音和多音，未匹配目标仍可记漏音，两者分别说明。

## 指标和解释

记 C 为正确匹配起音数、T 为可观测目标起音数、I 为用户有效起音数。音高召回=C/T，输入准确率=C/I；分母为零显示“不适用”。早晚分布只针对匹配音，报告误差中位数和 p95 绝对误差；不把漏音从总体结果中隐藏。

不生成未经验证的加权总分。等待模式展示目标完成数、重试次数、错误音；节奏模式展示正确、错音、多音、漏音与节奏偏差。基础版本不评分指法、音色、表情、踏板艺术或手指时值，不能从这些统计推断音乐水平。

报告引用固定谱版本并区分反复 occurrence；可点击错误回到对应书面位置和演奏轮次。重练建立新 session，不覆盖旧记录。支持删除单次练习记录，且不影响项目。

## P3C 自由跟随候选

只有用户明确启用该扩展、真实标注数据齐备且验证完成后，才选择在线对齐或 HMM。必须给出候选位置、置信度、速度估计、失锁状态和恢复机制。任意跳段、复杂装饰音不作为默认能力。

跟踪位置与评分分离：为恢复位置跳过目标不能清除漏弹。低置信度停在最近可信位置，提示用户重新选择段落，不能随机跳到相似乐句。此模块未确定算法和达标门槛，当前不排入必须开发任务。

## 中断和数据保留

断连、页面隐藏、音频挂起时暂停会话并清音，保存已完成区间；中断时间不计入节奏误差。继续时倒数，从最近未完成目标开始，切断跨中断匹配窗口。结果标注部分完成，不能将未演奏尾段全部算漏音。

原始事件与会话结果仅本地保存，默认不上传。标注样本包含错漏音、插音、重复音、双手和弦、踏板、左右手不同节奏及中断；真实用户样本收集前须明确用途和保留方式。
