# 播放与 MIDI 规格

版本 v0.1；P1 播放、P2 MIDI。具体性能门槛只在 [测试与验收](测试与验收.md)维护。以下参数是可配置初值，未经设备实测不作为体验保证。

## 演奏计划

PlaybackPlan 记录 scoreRevision、编译 sessionId、有限小节演奏路径、每个 occurrence 的原始元素 ID、起始四分音符位置、音频相对秒、时长、力度与手别。非嵌套反复先展开，再处理 tie 与速度图。tie 链持续发声，仅首音触发 NoteOn；路径发生反复跳转时不把书面相邻关系误当演奏相邻。

循环按用户选择的连续书面小节边界定义，P1 循环模式忽略范围内反复标记，以避免双重循环歧义；界面明确提示。正常播放执行谱内反复。选择播放起点位于 tie 中途时，从该位置重新触发剩余持续时长；暂停恢复采用相同规则，不追补已过去的攻击事件。

BPM 以四分音符为单位，P1 范围工作默认 20–300；6/8 标记中明确该单位，避免把附点四分音符 BPM 当作 quarterBpm。用户整体变速是倍率，不写回谱内速度图。更改倍率时从当前音乐位置清理未来队列并重排，不重播过去事件。

## 音频与光标

首次用户点击播放或开启监听后才启动/恢复 AudioContext。第一阶段采用本地谐波合成钢琴，不下载采样；启动失败显示重试提示，停止清理振荡器并通过压缩器控制叠音峰值。未来若加入采样适配器，再实现 idle/loading/ready/error 状态和独立资源许可审查。

调度器按 AudioContext 时间提前入队，建议初始 lookAhead=100ms、检查间隔=25ms，实测后调整。检查间隔只负责补队列，发声时间使用绝对音频时间。requestAnimationFrame 仅更新视觉位置，从当前音频时钟反算音乐位置。

停止、跳转、切换项目、音频中断和 session 失效必须取消未来事件并清理持续音；支持左右手静音和总静音。静音不改变播放位置。页面隐藏时工作默认暂停播放/录制/练习并清音；用户显式继续后重建映射，不承诺后台不间断运行。

## MIDI 授权与设备状态

只在用户触发“连接键盘”时请求访问；检测安全上下文和 requestMIDIAccess，默认不申请 SysEx。设备状态为 unsupported、permission-needed、connecting、connected、disconnected、denied、error；状态转换可重试，但不循环弹授权。

当前必需能力是选择输入端口并接收演奏。向硬件输出 MIDI 为候选增强，不因设备面板出现“输出”概念而默认开发。先验证 USB MIDI；BLE、虚拟端口与厂商驱动设备逐项进入兼容清单。

归一化事件字段：sessionId、deviceId、channel、type（noteOn/noteOff/cc）、note?、velocity?、controller?、value?、timestampMs、clockDomain。浏览器事件时间转为单调时间；NoteOn 且 velocity=0 按 NoteOff；保存原始事件供诊断，不能把零力度触发计为新起音。

按键状态与踏板状态分别维护：NoteOff 结束手指按压，CC64≥64 表示踏板开启。软件发声按踏板延长声音，打谱和练习默认依据按键事件而非踏板后的声学持续长度。设备拔出清空按键/踏板及声音，并结束本次连续录制段。

## 步进录入

用户先选择活动手/声部、时值和插入点；按键只提供音高。第一 NoteOn 打开候选组，建议初始和弦窗口 80ms，窗口内新音合并为同一和弦；组内键全部释放且窗口结束后提交一次命令并推进光标。窗口后仍有键按住时显示候选，允许用户确认/取消；不要靠不可见超时强行生成音符。

监听与写谱独立：声音立即调度，乐谱按组提交；同键重新按下视为下一组起音。休止、时值和退格通过工具或快捷键输入。P1/P2 未承诺自动左右手识别，用户必须指定目标手。

## 固定速度录制与量化

录制固定文档 revision、目标手、起点、BPM 和普通/三连音网格；倒数后记录原始事件，停止时保留未完成段及截断标记。断连或后台中断不假装录制连续。

量化是独立预览：按延迟校准修正起音，将起止位置映射到所选网格；时长最少一格、正向优先处理相邻重复音，溢出小节拆分 tie。和弦聚合只在同一网格与阈值内进行；独立时长无法在单声部表达时列冲突，让用户修正，不能统一截成相同长度静默丢信息。

量化结果可试听、调整网格、取消；用户确认后一次事务写入，覆盖既有谱必须预览。保留原始 MIDI 以便重新量化，量化不是原始记录的覆盖写入。自由速度录制、自动左右手分离不在当前基线。

## 时钟校准

区分输入时间、逻辑判定时间、音频调度时间与声学出声时间。性能时间和 AudioContext 时间建立映射，音频暂停/恢复后映射失效并重建。用户可校准固定延迟；保存校准配置的设备与音频路径标识，切设备提示重新校准。

音频调度 API 的准确度不能代表真实键盘至扬声器延迟；必须使用外部录音/回环测量端到端链路。所有实时判定在本机进行，不依赖网络往返。
