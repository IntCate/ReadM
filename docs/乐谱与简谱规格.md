# 乐谱与简谱规格

版本 v0.1；本文是音乐支持规则的唯一维护位置。范围来源见 [需求与追踪](需求与追踪.md)。以下符号子集是实施基线建议；待决策项见 [风险与待决策](风险与待决策.md)。

## 支持表

| 音乐元素 | P1 工作基线 | 边界 |
|---|---|---|
| 乐器/双手 | 单钢琴、右手与左手，和弦、两手独立节奏 | 同手多独立节奏声部见 Q-01 |
| 谱表/音域 | 右手高音谱号、左手低音谱号；钢琴 A0–C8 | 超出音域拒绝；交叉谱表后置 |
| 调性 | 大调、自然小调；五线谱调号 -7 至 +7 | 简谱小调记法见 Q-02；不支持无调性 |
| 拍号 | 2/4、3/4、4/4、6/8；小节边界处变化 | 复合拍按实际八分音符分组 |
| 音符/休止 | 全、二分、四分、八分、十六分、三十二分 | 支持单附点；双附点后置 |
| 和弦 | 一个节奏事件内多个音高，共享起点及时值 | 独立释放时值需多个声部，不强塞进和弦 |
| 变音 | 升、降、还原；保留音高拼写 | 重升重降与微分音后置 |
| 延音/连线 | 相同音高 tie；基本 slur | tie 改变发声，slur 仅作表情标记 |
| 连音 | 同声部连续三等分、3:2 三连音 | 嵌套与复杂比例后置 |
| 小节 | 普通小节、显式弱起小节 | 弱起实际长度小于名义拍长且双手一致 |
| 反复 | 非嵌套起止反复，默认演奏两次 | 房子、D.C./D.S.后置；不隐式支持 |
| 速度/力度 | 小节边界速度；基础力度或默认力度 | 渐快渐慢、渐强弱、歌词与装饰音后置 |

## 双手布局

五线谱采用上下两行大谱表，简谱采用明确标记“右手”“左手”的两行。每个系统内共享小节边界，按事件起始拍位置建立公共列，左右手根据同一时间列布局。各手可以有不同数量的音符；不得按字符数量或事件索引机械对齐。

同一个和弦音高纵向堆叠，共享减时线与持续时值；高音至低音向下排列，按音高拼写计算八度点。宽度容纳不下时整小节移到下一系统；单小节仍过宽则允许横向滚动并提示，不压缩到重叠。P1 优先流式分系统布局，出版分页不是核心交付。

## 简谱记法工作约定

大调以主音为 1；自然小调暂按关系大调记法、主音为 6，待 Q-02 确认。调号标记说明数字与实际音高的关系；项目保存记法策略，不能切视图时临时猜测。实际音高与“数字+八度点+变音”双向转换使用同一策略。

以 C 大调为例，C4 为无八度点的 1，C5 为上加一点的 1，C3 为下加一点的 1；和弦各音分别标八度点。临时变音作用于同小节相同记谱音级和八度，跨小节重置；持续跨小节 tie 的音高不因重置改变。

四分音符为无减时线数字；八分/十六分/三十二分加一/二/三条减时线；二分、全音符以增时线表示；附点独立显示。休止用 0，时长仍由模型决定，长休止组合、拍分组和三连音标记须在 Q-02 谱例中验证。6/8 的拍分组按复合拍组织，减时线和增时线不随用户界面“每拍”用语改写实际时值。

延音线连接同音持续，slur 覆盖乐句；两种标记分别绘制和编辑。简谱编辑音高时，先选数字、八度与变音，转换为有拼写的音高；界面不能只改显示字符而保持旧声音。

## 不变量

同一项目两种视图保留相同音符 ID、音高拼写、时值、手别、声部与连接关系。切换视图不修改项目音乐 revision；仅修改独立的视图偏好。保存重开、播放、练习均读同一语义模型。布局坐标与文字宽度不是节拍事实来源。

支持范围内音乐不可因为排版失败而只保留右手。超范围导入必须报告具体元素并保留原始文件；只读预览可以独立提供，但不能计作该谱已可编辑。
