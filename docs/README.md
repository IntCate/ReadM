# 项目文档入口

文档基线：v0.1，2026-10-18。状态：第一阶段 Web 应用已实现，正在执行本地生产构建与浏览器验证；尚未完成真实多平台设备和声学验收。该版本不是全部细节均已获用户确认的声明。

## 已确认的产品约束

- 三个阶段均先交付 Web；移动端和桌面客户端是未来明确需求，当前不实现。
- 第一阶段必须支持双手钢琴谱、双手简谱编辑、两种视图切换和乐谱播放。
- 第二阶段增加 MIDI 键盘打谱及弹奏；第三阶段增加 MIDI 跟谱练习。

## 权威关系

用户明确要求优先。需求范围和确认状态以需求登记为唯一来源；各专业文档只定义自己的规则。出现矛盾时停止依赖该矛盾的实现，登记待决策并同步修复，不靠文件时间或“更详细”来推断优先级。技术建议不能自行升级为用户确认需求。

[初步调研快照](research/2026-10-18-初步调研快照.md)只保留研究依据，不是当前开发合同；其中旧工期、跨端方案、导出格式和高级功能建议不能扩大现行范围。旧文件名保留为导航入口。

应用源码与锁文件在 `apps/web/`；当前实现、技术偏差、测试结果与未完成验收见 [第一阶段实现与验证](第一阶段实现与验证.md)。需求确认状态与实现状态分别维护，不能把本地验证当作所有目标系统的生产验收。
