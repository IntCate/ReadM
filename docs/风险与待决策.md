## 风险

| ID | 风险 | 触发信号 | 应对与回退 |
|---|---|---|---|
| R-01 | 双手简谱可读性或编辑性能不达标 | 和弦碰撞、双手错列、重排过慢 | 优先验证；改布局和缓存，不取消双手编辑 |
| R-02 | 浏览器 MIDI/声学延迟不达标 | 指定组合测量超标或拒绝权限 | 优化调度、说明受限组合；不虚构原生端救场 |
| R-03 | 存储被清理或配额不足 | 保存失败、快照缺失 | 明确保存状态、导出备份、恢复候选 |
| R-04 | 音乐语义与显示绑定 | 切谱改音高、复制后 ID 冲突 | 核心不变量、回放与双视图样例验收 |
| R-05 | 文档范围漂移 | 候选功能进入必做任务、阈值多处冲突 | 单一登记源、变更记录、自动追踪检查 |
| R-06 | 自由跟随研究风险吞噬计划 | 错误恢复不稳定、缺真实标注集 | P3A/B 独立交付；P3C 独立评估 |
| R-07 | 资源不可分发 | 来源不明、仅个人用途许可 | 换为可分发资源，保留许可证据 |

## 决策记录格式

关闭问题时记录：日期、决策者、用户/实验依据、决定、影响需求、修改文档、验收变化、关联 commit。技术人员可调整实现默认值，但不得以解决问题之名降级用户已确认的双手或 Web 范围。
