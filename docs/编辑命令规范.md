# 编辑命令规范

版本 v0.1；支持元素见 [乐谱与简谱规格](乐谱与简谱规格.md)，实体约束见 [数据与文件规范](数据与文件规范.md)。

## 公共命令契约

命令输入包含 commandId、expectedRevision、命令参数和来源（pointer/keyboard/midi）。输出为成功后的文档、选择状态、影响小节及撤销事务，或带 code、位置与修复建议的错误。revision 不一致报 REVISION_CONFLICT；不得在旧选区上盲目重放。

所有命令先验证、再构造补丁、再整体校验、最后原子提交。用户一次操作只产生一个撤销步骤；自动补休止、跨小节拆音、修复连接与选择移动包含在同一步。布局和播放缓存不是补丁权威数据。

## 命令表

| 命令 | 前置条件 | 修改与选择结果 | 失败规则 |
|---|---|---|---|
| SetEvent | 有目标手、声部、拍位置、音高或休止、合法时值 | 覆盖目标时间区间；必要时拆分被覆盖事件；光标推进到结尾 | 无法合法拆分时返回预览冲突，不近似时值 |
| AddChordPitch | 目标为 chord | 加一个 Note，事件时长不变；选中新 Note | 重复音、超音域或 rest 目标拒绝 |
| SetPitch | 选中一个 Note | 保留 Note ID；预览并同步修改其完整 tie 链 | 不允许把半条 tie 改成不同音高 |
| SetDuration | 选中事件，给出可表示时值 | 覆盖延长区间；缩短部分补休止；保留起点 | 后续音符将被覆盖时必须先确认预览 |
| DeleteSelection | 明确的同声部区间/多小节选区 | 删除后补等时长休止；解除跨边界连接 | 不压缩时间轴、不改变另一手 |
| PasteSelection | 有剪贴板语义与目标 | 新建 ID，默认覆盖；双手小节复制保持相对拍位置 | 剪贴板声部映射不明确则要求选择 |
| SetMeasureContext | 停止播放，选中起始小节 | 调号改变记谱解释但默认保留实际音高；拍号变更先预览重分小节 | 不合法节奏无法重分则不提交 |
| Add/RemoveTie | 同音连续端点 | 修改连接并失效播放缓存 | 非相邻、不同音高拒绝 |
| Add/RemoveSlur | 合法乐句端点 | 只修改表情连接 | 悬空端点拒绝 |
| SetTuplet | 同声部连续可分组事件 | 按 3:2 更改组内时长并预览影响区间 | 组不完整或嵌套拒绝 |
| SetRepeat/Tempo | 小节边界合法，停止播放 | 更新规则并重编译演奏路径 | 嵌套反复、非正 BPM 拒绝 |
| Undo/Redo | 对应事务存在 | 恢复语义与选择；生成新 revision | 新编辑清空 redo；历史不跨项目混用 |

## 覆盖和跨小节规则

P1 默认覆盖而非整体插入时间线。SetEvent 在目标声部覆盖 `[start,end)`，其他声部保持不变。覆盖边缘落在旧事件内部时，保留未覆盖片段；有音高片段通过合法拆分与 tie 表达，休止不生成 tie。任何片段无法由支持时值表示则整体失败并提示调整网格。

新事件跨小节时按边界拆成多段，相同音高用 tie 连接。超出项目尾部可在预览中追加同上下文小节，确认后作为同一事务提交。不自动覆盖被占用的后续音符而不告知用户。

例：右手 m1 最后一拍输入二分 C4，生成 m1 最后一拍四分 C4 与 m2 第一拍四分 C4、同音 tie；左手事件完全不变。m2 第一拍若已有音符，先预览覆盖内容，取消后项目 revision 不变。

## 调号、手别与删除连接

修改调号默认保持实际音高，重新计算临时变音与简谱数字；“移调作品”是独立后续命令，不隐含在改调号中。手别变更需要目标声部映射和覆盖预览，不靠拖过分隔线自动移动数据。

删除连接端点时删除受影响 tie/slur；复制时只复制两端均在选区内的连接，向用户提示跨选区连接未复制。不留下引用不存在音符的记录。

## 历史与持久化

历史只针对音乐编辑；选中、滚动、切视图不进入撤销栈。P1 历史可只保留当前会话，重开后撤销栈为空需在界面说明；自动保存必须保存最新完整文档，不能依赖内存历史恢复作品。多标签页写入冲突由仓储拒绝并允许另存副本。
