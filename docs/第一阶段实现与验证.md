# 第一阶段实现与验证

日期：2026-10-18；应用版本 0.1.0；状态：Web 第一阶段代码已实现，本地生产构建和浏览器验证通过。尚未完成所有目标操作系统、音乐顾问与声学同步验收；不将这些结果表述为全面生产兼容。

## 运行与代码位置

应用入口为 [apps/web/README.md](../apps/web/README.md)。从该目录运行 `npm ci`、`npm run dev`，打开终端打印的本地 URL。生产构建运行 `npm run build`，静态产物在 `apps/web/dist/`。

| 模块 | 当前实现 |
|---|---|
| 乐谱模型与校验 | `apps/web/src/core/score.ts`：有理数、双手、音符/和弦/休止、连接、三连音、调拍号、版本化项目 |
| 编辑命令 | 同一核心模块中的原子纯函数，界面负责覆盖预览与确认；会话撤销重做 |
| 演奏编译 | `apps/web/src/core/playback.ts`：反复 occurrence、延音合并、速度、循环范围 |
| 双谱渲染 | `apps/web/src/components/ScoreView.tsx`：VexFlow Bravura、简谱 SVG、公共拍列、动态谱面高度、可视区域渲染 |
| 浏览器服务 | `apps/web/src/platform/`：Web Audio 本地合成钢琴、IndexedDB 原子写入与上一保存快照 |
| 工作台 | `apps/web/src/App.tsx`：项目管理、键鼠输入、双谱切换、属性编辑、播放控制、导入导出 |

## 第一阶段已实现范围

- 双手五线谱与双手简谱均可创建、选择和编辑，左右手独立节奏、和弦、休止及试听。
- 支持文档子集中的音域、调号、拍号、单附点、临时升降还原、三连音组、弱起、tie/slur、非嵌套两次反复及小节边界速度。
- 覆盖输入、自动补休止、跨小节拆音和延音、增加小节、单音高/时值修改、指定手别的小节复制粘贴、删除、撤销重做。
- 从头/选区位置播放、暂停停止、变速、小节循环、节拍器、左右手静音、光标随播放位置及自动滚动。
- 本地项目列表、标题编辑、自动保存、手动保存、上一保存快照恢复、刷新重开、多标签页写者保护、自有项目文件导入导出和来源项目 ID。
- 限额校验、未知格式/字段拒绝、损坏文件保护、保存失败保留内存及导出路径。

当前复制单位为所选事件覆盖的小节，不是任意节拍片段；界面明确提示所复制的小节与手别。默认输入采用覆盖模式，涉及其他音符或末尾追加小节时先确认。

界面截图：[双手五线谱](assets/第一阶段-五线谱.png)、[双手简谱](assets/第一阶段-简谱.png)。

## 技术决策与工作默认值

第一阶段采用每手一个独立节奏声部、声部内和弦；自然小调采用关系大调记法，C 大调 C4 为无点 1。这些是此前 Q-01/Q-02 的工作默认，用户尚未单独确认其最终边界，没有以实现完成为由关闭这些产品问题。

音频改用直接 Web Audio 谐波合成，不引入 Tone.js 和采样下载；保留独立音频适配类。该变更减少网络与资源依赖，属于实现选择，未改变试听需求；录音级钢琴采样仍可后续替换。Bravura/Academico 字体及组件许可随静态资源分发；来源为 VexFlow 包和 [vexflow-fonts](https://github.com/vexflow/vexflow-fonts)。

首次项目结构为 schemaVersion=1，当前没有更早发行格式要迁移；未知版本拒绝并保留原件。第一阶段不实现 MusicXML/MIDI 文件交换、打印/PDF、MIDI 硬件接入、跟谱、同手复调、移动或桌面客户端。

## 当前限制与未完成验收

- 没有做外部录音/回环的 10 分钟视听偏差测量，也没有硬件 MIDI 测量；后者属于第二阶段。
- 待音乐顾问对大小调、复杂和弦、八度点和节奏分组做专业可读性评审；自动截图不替代音乐审查。
- 未完成 Windows、Edge、Safari 等真实宿主矩阵及最低配置冻结，兼容声明仍受 Q-03 限制。
- 依赖自有 JSON 文件，不支持任意历史软件文件；完整离线启动缓存和云备份未实现。
- 项目在浏览器本地保存，不同域名/浏览器不共享数据；迁移需导出再导入。未提交的内存修改不能在浏览器崩溃后保证恢复。
- Web 第一阶段已可运行，但上述限制使“全部生产验收通过”状态尚不能成立。
